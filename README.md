# Instagram aplikace

Menší webová aplikace inspirovaná Instagramem, vytvořená v ASP.NET Core. Projekt slouží především jako ukázka práce s MVC architekturou, databází, autentizací a základními funkcemi sociální sítě.

## Funkce

- Registrace a přihlašování uživatelů
- Správa uživatelských profilů
- Vytváření a prohlížení příspěvků
- Komentáře
- To se mi líbí
- Zasílání zpráv mezi uživateli
- Autentizace a správa uživatelů pomocí ASP.NET Core Identity

## Technologie

- C#
- ASP.NET Core MVC
- ASP.NET Core Identity
- Entity Framework Core
- HTML / CSS (Bootstrap)
- SQL

## Architektura

Aplikace využívá **MVC (Model-View-Controller)** architekturu, která odděluje datovou vrstvu, aplikační logiku a prezentační část.

## Poznámka

Projekt vznikl původně jako školní úkol a sloužil především k procvičení vývoje webových aplikací v ASP.NET Core, práce s databází, autentizace uživatelů a MVC architektury.
